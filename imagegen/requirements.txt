# Image generation environment — deliberately separate from backend/requirements.txt.
# Install into its own venv (imagegen/.venv) so the main API's dependencies stay light:
#
#   cd imagegen
#   python -m venv .venv
#   .venv\Scripts\activate      # Windows
#   pip install -r requirements.txt
#
# GPU strongly recommended. On CPU-only hardware, expect generation to take minutes per
# image even with the fast, few-step model this project defaults to (IMAGE_GEN_MODEL) —
# that's a hardware limit, not a bug.
