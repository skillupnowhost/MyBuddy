# Video generation environment — deliberately separate from backend/requirements.txt and
# from imagegen/requirements.txt. Install into its own venv (video/.venv) so the main API's
# dependencies stay light:
#
#   cd video
#   python -m venv .venv
#   .venv\Scripts\activate      # Windows
#   pip install -r requirements.txt
#
# GPU strongly required in practice. Text-to-video diffusion is dramatically heavier than
# text-to-image (many frames, each its own denoising process) — on CPU-only hardware this
# will not complete in any practical amount of time, not just "be slow." See README.md.
